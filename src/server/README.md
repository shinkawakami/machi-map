# src/server — DB を引くもの

ここに置くのは **Prisma を通して Postgres を引くモジュールだけ**。
ルートハンドラ（`src/app/api/**`）とサーバーコンポーネントからしか読まない。

この層を分けているのは、**境界をコメントではなく置き場所で守る**ため。
以前は同じ `src/lib` に純粋な関数と Prisma を引く関数が同居していて、
クライアントの部品が「型だけだから」と `import type` でこちらへ手を伸ばしていた。
型は消えるので動きはするが、**うっかり値を1つ import した瞬間に
Prisma がブラウザのバンドルに入る**。

対になる置き場所:

| 置き場所 | 動く場所 | 例 |
|---|---|---|
| `src/lib` | どこでも（DB もブラウザ API も触らない） | 災害8種・種別・格子の吸着・API の型 |
| `src/client` | ブラウザだけ | URL と localStorage・fetch の口 |
| `src/server` | サーバーだけ | Prisma のクエリ・キャッシュヘッダ |

> `server-only` パッケージを入れれば、間違えたときにビルドが落ちるようにできる。
> まだ依存に入れていないので、いまは置き場所の規約で守っている。
